# Contributing to BT Messenger

Thanks for your interest in contributing!

## Setup

```bash
git clone https://github.com/sagar0163/bt-messenger.git
cd bt-messenger

# Install dependencies
pip install -r requirements.txt

# Run the messenger
python -m src.messenger
```

## Making Changes

1. Fork the repo
2. Create a branch: `git checkout -b feature/your-feature`
3. Make improvements
4. Commit: `git commit -m "feat: add new feature"`
5. Push to main: `git push origin main`

## Ideas for Contributions

- 🔒 End-to-end encryption
- 💬 Message reactions
- 📎 File transfer
- 👥 Group chat
- 📱 Mobile app
- 🔔 Notifications
- 📊 Message history

## Testing

```bash
# Run tests
pytest tests/
```
